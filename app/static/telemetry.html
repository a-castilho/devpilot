TERMINAL

Hook Bash opt-in

A captura de terminal fica desligada por padrão. Habilite-a explicitamente com um token de acesso de telemetria; o bootstrap token nunca é reutilizado.

export DEVPILOT_URL=http://127.0.0.1:8080
export DEVPILOT_TERMINAL_CAPTURE=1
export DEVPILOT_TELEMETRY_TOKEN='seu-token-de-acesso'
source "$HOME/Documents/devpilot/tools/devpilot_terminal_capture.sh"
Após 401/403, o helper abre um circuit breaker persistente para esse token e para de gerar novas tentativas até a credencial ser trocada.
