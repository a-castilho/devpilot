# DevPilot 1.1.0 — Confiabilidade e Runtime Seguro

**Preparada em: 25/08/2026**

A versão 1.1.0 consolida a recuperação do incidente de travamento de login/pós-login e transforma as correções em padrões permanentes de engenharia.

## Destaques

- boot pré-autenticação mínimo, limitado a `acs-loader.js` e `auth-ui.js`;
- core autenticado determinístico, limitado a `app.js` e `feature-loader.js`;
- módulos opcionais carregados somente sob demanda;
- gate `DevPilot policy` para impedir loaders ocultos, segunda onda automática e novos `MutationObserver` globais em módulos comuns;
- runtime local seguro com identificação de serviço, PID, porta, commit, health check e rollback;
- fallback para GitHub Actions self-hosted runner quando os minutos hospedados estiverem indisponíveis;
- versão de aplicação, API e pacote centralizada em `app.version.__version__`.

## Validação já realizada

- policy gate local aprovado;
- testes anti-regressão de boot aprovados;
- sintaxe Python, JavaScript e Bash crítica aprovada;
- PR #122 permanece como gate de integração antes de entrar na `main`.

## Critério de publicação

A tag/release `v1.1.0` só deve ser criada depois de `DevPilot policy` e `DevPilot quality` executarem com sucesso e a PR correspondente ser integrada à `main`.
