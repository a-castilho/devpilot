# DevPilot 1.1.1

## Objetivo da versão

Fechar a progressão do Build Game para que uma fase concluída pelo executor não seja tratada automaticamente como entrega real no sistema do cliente.

## Gate de entrega real

- cada fase concluída gera uma verificação independente antes da próxima fase ser liberada;
- o verificador não aceita `status=completed` como evidência suficiente;
- a validação compara o objetivo da partida com critérios de aceite concretos;
- evidências e pendências devem ser registradas em `.devpilot/build-game.md`;
- são exigidos, quando aplicáveis, testes, lint/typecheck, build, smoke, migrações e validação do fluxo real;
- URL existente, relatório ou ausência de erro não contam isoladamente como vitória;
- na fase 6, o objetivo completo é revalidado ponta a ponta e confrontado com o Delivery Target do projeto.

## Compatibilidade

A implementação reutiliza o modelo atual de tarefas do Build Game e não exige migração de banco. O gate é carregado apenas no runtime isolado do jogo, preservando o dashboard e os fluxos estáveis existentes.

## Regressões protegidas

- ordem de carregamento `build-game.js -> delivery-gate.js -> game-bootstrap.js`;
- presença do marcador dedicado `[DEVPILOT_DELIVERY_VERIFIER_V1]`;
- bloqueio de progressão até conclusão da tarefa verificadora;
- proteção contra criação infinita de verificadores após aprovação;
- versão da aplicação, API e pacote fixada em `1.1.1` pela fonte única `app.version.__version__`.
