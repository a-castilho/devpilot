# DevPilot 1.1.1

Data: 2026-08-31

## Integração

Esta versão consolida a esteira V2 do Jogo de Construção com o layout responsivo e a navegação mais recente.

## Correções

- preserva a esteira V2 de 7 etapas e suas correções de falha real;
- mantém a separação entre Worker de tarefas e GitHub Actions Runner;
- impede que a descrição geral do projeto seja usada automaticamente como objetivo de uma nova rodada;
- reincorpora o conjunto mais recente de navegação, menu mobile, sidebar e regras responsivas do layout V38;
- adiciona teste de regressão para impedir nova separação entre a esteira V2 e o layout/menu.

## Compatibilidade

A atualização preserva os fluxos de backend e worker da V2 e substitui somente os ativos de layout/navegação selecionados pela versão mais recente já validada na branch de interface.
