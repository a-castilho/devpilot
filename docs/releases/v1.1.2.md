# DevPilot 1.1.2

Correção de integração da esteira V2 com a experiência mobile.

## Correções

- tarefas antigas do Jogo V1 deixam de competir visualmente com a Pipeline V2 quando já existe tarefa V2 do mesmo projeto;
- ações de tarefa no mobile passam a usar uma única grade responsiva, eliminando sobreposição entre Próximo, Continuar automaticamente, Retomar e Arquivar;
- botões longos podem quebrar linha sem invadir controles vizinhos;
- posicionamento legado/absoluto é neutralizado na área de ações;
- cache do stylesheet de tarefas é invalidado para garantir a aplicação da correção;
- versão do serviço atualizada para 1.1.2.

## Preservado

- Pipeline V2 com sete etapas;
- objetivo explícito por rodada;
- preservação da falha real;
- observabilidade do worker;
- layout/menu consolidado na 1.1.1.
