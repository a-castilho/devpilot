## Descrição e evidências da PR

Corrige a entrada do Modo Jogo no mobile quando a navegação cai em `/game` ou `/game/`.

Causa: essas rotas eram tratadas pelo fallback SPA principal, enquanto o documento isolado do jogo existe em `/game/index.html`. Isso pode produzir a tela escura vazia antes do bootstrap do jogo.

Mudanças:
- canonicaliza `/game` e `/game/` para `/game/index.html` no loader inicial que já é servido pelo fallback SPA;
- preserva query string e hash;
- executa o redirecionamento antes do fluxo de autenticação/carregamento;
- adiciona contrato de regressão garantindo que o documento canônico mantém o shell visível de boot.
