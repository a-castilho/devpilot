## Descrição e evidências da PR

Ajusta a tela Execuções a partir do print mobile após o V40.

Causa raiz:
- o V41 marcava `failure-recovery` para ocultação;
- o V40, carregado depois, aplicava `display:grid !important` com maior/igual especificidade e fazia as linhas internas reaparecerem;
- alguns renderizadores antigos também substituem o tbody sem disparar o evento esperado, deixando `Carregando execuções...` preso.

Correções:
- autoridade CSS final para manter tarefas internas ocultas mesmo após o V40;
- reconciliação por `MutationObserver` quando o tbody é refeito;
- contador atualizado mesmo quando o renderer não emite evento;
- renderer legado de 5 células recebe metadados e ações compactados no telefone;
- `FAILED`/`COMPLETED` legados são apresentados como `Falhou`/`Concluída`;
- botões de ação no mobile ficam em grid responsivo e com tamanho de toque consistente.

Sem alteração de backend ou banco.
