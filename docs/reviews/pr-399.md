## Problema reproduzido
Falhas de autenticação GitHub podem ser classificadas como autorização humana antes de o recovery automático esgotar as credenciais e alternativas administradas pelo DevPilot. Recoveries históricos podem permanecer em `awaiting_approval` mesmo quando o diagnóstico atual já é automático.

## Regra desejada
A recuperação deve ser automation-first: diagnosticar, tentar alternativas seguras, informar o que ocorreu, retestar a mesma etapa e só então retomar a esteira. Ação humana fica restrita a uma fronteira externa realmente comprovada após esgotamento das alternativas automáticas.
