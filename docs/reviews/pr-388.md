- observação passiva não cria tempestade de retries/autocorreções, apenas acompanha o estado real e valida deploy em andamento;
- quando backend chegar a `ready`, a URL aparece automaticamente;
- UI passa a mostrar `Aguardando publicação/correção` e informa que continua acompanhando;
