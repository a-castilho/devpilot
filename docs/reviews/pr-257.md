## Descrição e evidências da PR

Corrige o segundo erro visível no card de projeto mobile: `Falha na publicação` com mensagem genérica.

Problemas encontrados:
- Render recebia `project.repository_url` no formato bruto; URLs GitHub com sufixo `.git` ou formato SSH podem ser rejeitadas como `invalid or unfetchable`;
- o backend já registrava a causa técnica segura (`render: HTTP 400`, `vercel: HTTP ...`, etc.) no audit, mas substituía a mensagem exibida por texto genérico.

Correções:
- normaliza o campo `repo` enviado ao Render para `https://github.com/owner/repo`, removendo `.git` e convertendo SSH;
- preserva Vercel scope existente;
- recupera do audit a causa técnica segura da última falha de delivery e a apresenta no `last_error`;
- limita/normaliza a mensagem exposta para uma linha de até 180 caracteres;
- adiciona testes para URL Render HTTPS/.git/SSH e visibilidade da causa técnica.

Não altera credenciais nem expõe response body/tokens.
