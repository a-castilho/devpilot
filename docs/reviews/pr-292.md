## Descrição e evidências da PR

Corrige a regressão de desempenho mobile introduzida no retry v62.

Causa:
- cada toque para iniciar/repetir fase fazia um GET de histórico antes do POST;
- depois do POST o fluxo ainda executava novas leituras para render/gates;
- no celular isso transformava um toque em várias requisições seriais e dava sensação de travamento;
- o cache também estava com revisões diferentes entre assets críticos.

Correção:
- remove o GET de preflight antes do POST;
- mantém dedupe em memória por ação semântica enquanto a criação está em voo;
- recovery só consulta histórico se o POST falhar e ignora estados failed/cancelled/archived como falso sucesso;
- mantém distinção entre etapa base, gate e correção pelo título;
- aumenta o yield entre enhancements no mobile de 45ms para 90ms;
- aplica a mesma revisão v63 aos cinco assets críticos do documento standalone;
- mantém substrings v60/v62 para compatibilidade com contratos anteriores;
- adiciona testes específicos contra regressão de freeze mobile.

Resultado esperado: abrir e tocar no jogo continua responsivo no celular; retry cria nova execução sem consulta prévia pesada e duplo toque continua protegido.
