## Descrição e evidências da PR

## Objetivo
Implementa um módulo isolado de Blueprints para o DevPilot reaproveitar estruturas de projetos validadas em vez de recriar tudo do zero.

## Entregas
- núcleo portátil em `app/blueprints` sem dependência de FastAPI/SQLAlchemy;
- registry persistente e versionado;
- matcher por stack/capabilities/tags/texto/maturidade;
- renderer parametrizado com proteção contra path traversal e secrets;
- materialização de arquivos;
- métricas de uso/sucesso;
- API em `/api/blueprints`;
- três blueprints iniciais;
- seleção automática durante o provisionamento de projeto;
- fallback seguro para geração convencional;
- documentação em `docs/BLUEPRINTS.md`;
- testes unitários do núcleo.

## Compatibilidade
O módulo foi estruturado para futura extração para outro sistema. A camada DevPilot está separada do núcleo.

## Observação
A seleção é registrada em `codex_config` com `generation_strategy=blueprint_delta` quando houver compatibilidade, mantendo `from_scratch` quando não houver blueprint adequado.
