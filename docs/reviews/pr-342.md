## Descrição e evidências da PR

PR empilhada para validar os bloqueios de autenticação encontrados após liberar os gates anteriores.

## Problema
O runtime atual inicia usuários sem sessão na home pública e só materializa `#auth-email` depois do clique em `#public-login`. Alguns contratos e E2E ainda assumiam o formulário de login imediatamente disponível ou dependiam de comentários/formatação exatos do JavaScript.

## Correção

- atualiza os helpers de login dos E2E crítico, Projetos mobile e RAG para seguir a home pública quando necessário;
- mantém o caminho de login direto compatível caso o formulário já esteja materializado.
