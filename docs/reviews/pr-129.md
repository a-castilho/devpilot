## Problema
A rota catch-all da SPA testava `STATIC / path` com `is_file()` antes de normalizar e limitar o caminho. Isso permitia aliases léxicos/decodificados atingirem arquivos fora do contrato esperado e, em especial, resolverem para `index.html` sem passar pelo shell autenticado.

## Correção
- resolve o candidato de forma canônica;
- exige que o arquivo permaneça dentro de `STATIC`;
- impede qualquer resolução canônica para `index.html` de ser servida diretamente;
- preserva assets estáticos legítimos;
- adiciona regressões para index, escape, asset válido e caminho inexistente.
