## Descrição e evidências da PR

## Escopo

Implementa o RAG desacoplado do DEVpilot com pgvector, Redis, embeddings externos, indexação incremental, chat com RAG/LIVE e controles do Super Admin.

## Incluído
- bounded context `app/rag`
- modos `NO_RAG`, `RAG`, `LIVE` e `RAG_LIVE`
- PostgreSQL + pgvector para documentos/chunks
- Redis com cache limitado e invalidação por projeto
- sanitização de segredos antes de indexar/embeddar
- chunking low-RAM e hash incremental
- embeddings externos configuráveis
- retrieval vetorial com isolamento por organização/projeto
- indexação assíncrona em fila no worker existente
- progresso, retry e métricas dos jobs
- integração do contexto RAG/LIVE ao `/api/chat`
- telemetria de retrieval sem persistir o texto bruto da consulta
- persistência das configurações RAG em PostgreSQL
- auditoria das ações administrativas
- painel Super Admin lazy-loaded para saúde, configurações, jobs, métricas, cache e teste de retrieval
- testes unitários/integração do fluxo RAG

## Segurança e operação
- RAG desativado por padrão
- Redis é apenas cache, nunca fonte de verdade
- isolamento estrito por `organization_id + project_id`
- falhas de cache/telemetria degradam o recurso sem invalidar o core
- worker RAG reutiliza o processo existente para manter baixo consumo de memória
