## Descrição e evidências da PR

Corrige a falha de publicação mesmo com as keys válidas.

Causa observada em produção local:
- a Neon aceita a criação do projeto, mas a branch `main` ainda está finalizando quando o DevPilot tenta criar `homolog`;
- respostas temporárias 423/503 eram tratadas como falha definitiva;
- como o estado parcial ainda não havia sido persistido, o retry criava outro projeto Neon;
- Vercel já pode ter o projeto existente e o fluxo tentava criar outro;
- Vercel sem Team ID explícito validava a key no usuário, mas publicava fora do team correto.

Correções:
- retry exponencial para Neon em HTTP 423/503;
- reconciliação/reuso de projeto Neon existente, branches, database e role;
- reuso de serviço Render existente;
- reuso de projeto Vercel existente;
- descoberta automática do único Team ID da Vercel pela key;
- mantém a descoberta automática de org/workspace para Neon e Render;
- novos testes de regressão de idempotência e retries.
