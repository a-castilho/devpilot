## Objetivo

Adicionar ao DevPilot um fluxo auditável para criar um projeto novo do zero e acompanhar a entrega até PR draft/CI, mantendo homologação, merge e deploy sob gates explícitos.

## Implementado

- criação confirmada de repositório privado na organização GitHub configurada;
- `auto_init=true` para garantir branch inicial clonável;
- registro automático de `Project` e `Repository`;
- criação opcional de tarefa inicial completa (health, testes, README e CI);
- persistência da branch criada pelo worker;
- endpoint de status ponta a ponta;
- publicação controlada somente após execução local em `review`;
- commit/push apenas da branch da tarefa após confirmação explícita;
- criação/reuso de Pull Request draft;
- leitura de status/check-runs do CI;
- merge e deploy continuam bloqueados até validação;
- documentação e testes unitários do novo fluxo;
- versão API/package 1.1.0.

## Segurança

Credenciais GitHub permanecem no vault. Criação remota e publicação exigem Super Admin + confirmação explícita. Nenhuma ação deste PR realiza merge ou deploy.

## Validação esperada

O CI do próprio DevPilot deve compilar fontes, executar pytest e construir a imagem Docker. Após CI verde, o fluxo pode ser testado localmente criando um repositório descartável pela nova API.
