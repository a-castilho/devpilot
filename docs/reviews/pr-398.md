## Problema
Execuções de projeto ainda podem falhar em `git clone` com `terminal prompts disabled` mesmo quando a credencial GitHub já está salva no painel administrativo. O resolver considera apenas `provider=github`, enquanto o painel Cloud salva GitHub como `cloud:github` (e existe legado `cloud-github`). Além disso, nem todo caminho do executor usa obrigatoriamente o checkout autenticado com preflight.

## TDD
Este PR começa com testes de regressão que exigem:
- aceitar `github`, `cloud:github` e `cloud-github` como fontes GitHub do mesmo workspace;
- extrair o token do formato legado JSON sem expor segredo;
- instalar o checkout autenticado no executor global, não apenas em fluxos específicos.

A implementação será adicionada após confirmar o RED no CI.
