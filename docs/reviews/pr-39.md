## Descrição e evidências da PR

## Objetivo
Os provedores estavam salvando catálogos inteiros (ex.: 118 modelos OpenAI), embora o DevPilot normalmente precise apenas de um conjunto pequeno de modelos de texto/código.

## Implementação
- adiciona recomendação automática de até 6 modelos úteis por provedor;
- evita persistir todo o catálogo quando nenhuma seleção explícita é feita;
- adiciona botão **Editar modelos** em cada conexão configurada;
- permite buscar, selecionar e salvar modelos sem reenviar a API key;
- permite reduzir uma seleção antiga mesmo quando a API do provedor estiver temporariamente indisponível;
- impede que **Atualizar catálogos** sobrescreva a seleção do usuário;
- mantém catálogo disponível separado dos modelos efetivamente selecionados;
- destaca conexões com mais de 6 modelos e oferece **Usar recomendados**;
- adiciona testes para recomendações e validação de sintaxe do frontend.

## Segurança
A API key permanece criptografada no servidor e nunca retorna ao navegador. Atualizações de modelos são auditadas somente por provedor, conexão, quantidade e origem da validação.
