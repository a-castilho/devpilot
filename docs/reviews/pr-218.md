## Problema
O instalador de comandos do DevPilot podia adicionar `atualizar() { ...; }` depois de um alias legado `atualizar=...` já existente no `.bashrc`. Em Bash interativo, aliases são expandidos durante o parsing e isso pode causar `syntax error near unexpected token '('` ao abrir o shell.

## Correção
- neutraliza aliases legados dos nomes gerenciados pelo DevPilot antes de declarar as funções;
- preserva os comandos `atualizar-local`, `atualizar`, `reconstruir-sistema` e `reconstruir`;
- mantém o instalador idempotente pelo bloco gerenciado existente;
- valida o candidato com `bash -n` antes de substituir o `.bashrc` real;
- mantém o `.bashrc` atual intacto se a validação sintática falhar;
- não remove aliases pessoais do arquivo: apenas executa `unalias` em runtime para os nomes que o DevPilot passa a gerenciar.

## Testes adicionados
`tests/test_linux_alias_installer.py` cobre:
- `.bashrc` iniciado com aliases legados conflitantes;
- execução do instalador duas vezes;
- apenas um bloco DevPilot após reinstalação;
- `bash -n ~/.bashrc` válido;
- abertura de Bash interativo com os quatro comandos resolvendo como funções;
- garantia de que a validação acontece antes da gravação do arquivo real.
