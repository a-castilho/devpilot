## Descrição e evidências da PR

## Problema
No modo leve/mobile, a tela de Projetos não pré-carrega o Project Builder. O clique em **Novo projeto** cai no roteador global, que espera scripts e, para Super Admin, também pode esperar organizações antes de exibir a view. Quando a API ou o carregamento está lento, o front parece travado.

## Correção
- intercepta o clique de Novo projeto em modo leve na fase de captura;
- abre `new-project` imediatamente, antes de qualquer carregamento remoto;
- exibe estado visual de carregamento no Builder;
- carrega `projectBuilder` de forma assíncrona;
- carrega/sincroniza organizações depois que a tela já está disponível;
- evita reentrada do clique durante a abertura;
- mantém o fluxo normal intacto fora do modo leve/mobile.

## Testes
Adicionado `tests/test_new_project_nonblocking_low_power.py` cobrindo interceptação, ordem abrir-view -> carregar bundle e carregamento posterior das organizações.
