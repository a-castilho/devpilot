## Objetivo
Mover a progressão da rodada do navegador para o worker do DevPilot. O usuário pode fechar o celular ou sair da tela e a rodada continua.

## Implementado
- `GameRoundOrchestrator` server-side para gate → próxima fase;
- 7 fases continuam obrigatórias e só avançam após gate independente concluído;
- retry automático limitado a 3 tentativas para fase/gate com falha;
- a resposta/log da tentativa anterior é incorporada no prompt de correção;
- detecção/log de tarefa parada em `queued` por 5 minutos;
- worker dedicado e `EmbeddedWorker` executam o orquestrador;
- navegador vira observador passivo: não cria gate nem próxima fase;
- `flow-keeper` só redesenha quando o estado remoto realmente muda, evitando piscar;
- `delivery-gate.js` legado permanece no repositório para compatibilidade, mas não é carregado no boot v77;
- testes de contrato atualizados.
