## Bloqueio encontrado durante a implantação da correção da esteira
O `DevPilot runtime image` falhou no `docker build` antes do deploy de homologação.

Causa: o Dockerfile executava `pip install '.[postgres]'` depois de copiar apenas `pyproject.toml`. O projeto usa versão dinâmica `app.version.__version__` e descoberta de pacotes `app*`, então o setuptools tenta importar `app` durante o build e falha com `ModuleNotFoundError: No module named 'app'`.

## Correção
- copia `pyproject.toml`, documentação necessária e `app/` antes do `pip install`;
- mantém o restante da imagem inalterado;
- adiciona teste de regressão garantindo que `COPY app ./app` permaneça antes da instalação do projeto.

Esta correção é necessária para liberar o gate `DevPilot runtime image` e permitir que o workflow `Deploy Homolog` execute.
