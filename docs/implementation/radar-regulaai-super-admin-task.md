# Radar Regula AÍ — tarefa do Super Admin

A entrega histórica do Radar Regula AÍ é importada de forma idempotente para o painel `Tarefas ADM` quando o projeto Regula AÍ está cadastrado no workspace.

Critérios: ownership pelo `SUPER_ADMIN`, status `completed`, prioridade 90, vínculo com o PR Regula AÍ #79, ausência de duplicação em leituras sucessivas e isolamento entre Super Admins.
